# Section patterns

| Section | Layout | Notes |
|---|---|---|
| Testimonials | label, heading, grid of quote cards (quote, name, role, optional photo) | 1-6 quotes; 4 quotes = 2x2; real quotes only; library: `testimonials` |
| Contact | heading + intro; left: address / phone / e-mail / hours; right: the site's form | no form plugin -> a mailto button; library: `contact` |
| Hero | heading (max 10 words), one sentence, 1-2 buttons, image beside or below | the one h1 lives here, not in components |
| Features | heading, 3 or 6 cards: icon, title, one sentence | equal text length per card |
| Pricing | 2-3 plan cards, one highlighted, price, 4-6 bullets, one button each | highlight with border, not size |
| FAQ | heading, accordion of 5-8 questions | questions as buttons, one open at a time |
| CTA band | one sentence + one button on a contrasting background | one action only |
| Logo strip | 4-6 logos, grayscale, same height | alt text = company name |

Rules for all: one message per section; consistent card style; section spacing equal to the site's; every image has alt text; the section reads correctly with images off.
